# Privacy Policy

This plugin lets Dify applications search the web through the SERPdive API.

## What data is sent, and where

- The search query and the search parameters you set (model, answer, max results) are sent over HTTPS to `api.serpdive.com`, operated by SERPdive, for the sole purpose of running the search.
- Your SERPdive API key is stored by Dify's credential storage and sent as an `Authorization` header with each request so SERPdive can authenticate you.

## What the plugin itself collects

Nothing. The plugin does not collect, store, log, or share any user data. It keeps no state between invocations, adds no analytics, and contacts no third party other than the SERPdive API.

## SERPdive's handling of the data

SERPdive processes the query to run the search and bill the account. See the SERPdive privacy policy for details: https://serpdive.com/privacy
